## Принятые решения

| Решение | Причина |
|---|---|
| Нейтральная графитовая палитра, тёмная тема по умолчанию | Пользователь попросил убрать красный акцент |
| Отдельная HTML-страница на каждую тему | `JiraWorkflow.html` разросся, Scrum/Kanban вынесены |
| Ссылка из плана только на конкретную фразу темы | Весь блок компетенции — слишком широко для одной подтемы |
| У каждого вопроса два ответа: модельный и «своими словами» | На интервью заученный текст слышно сразу |
| Чекбоксы и тема в localStorage, общий ключ между страницами | Прогресс сохраняется между визитами |
| Ссылки на Confluence не добавляем | Просьба пользователя |
| Справочник переименован `AGENTS.md` → `PROJECT-NOTES.md` | Не подмешивать контекст в каждую новую сессию |
| `DeployStrategies.html` переписана «для новичка» | Пользователь впервые слышит про стратегии: нужны аналогии и шаги, а не термины |
| В колонке «Level 3» плана — нумерованные списки вместо `;` | Разделитель терялся, было непонятно, где кончается одна тема и начинается другая |
| Общие стили и скрипты вынесены в `assets/` | Единый вид и одна точка правки вместо копий в каждом файле |
| HTML в корне, служебные файлы в `docs/` | Страницы остаются рядом, ссылки короткие, прогресс в браузере не сбрасывается |
| Главная `index.html` с прогрессом и картой курса | Нужна точка входа и обзор, а не только отдельные страницы |
| Блок 4 разбит на `Algorithms.html` и `Patterns.html` | Алгоритмы и паттерны — разные темы; одна страница получилась бы слишком большой |
